🦉 IAU WiseOwl 
An intelligent and integrated academic companion platform designed to help university students organize their daily academic lives, manage schedules, track tasks, and handle cooperative training opportunities all in one place. 

🚀 About the Project
IAU WiseOwl is a centralized web and mobile-friendly academic platform created to eliminate information fragmentation for students. The system consolidates essential student activities into a modern, easy-to-use interface, enhancing academic planning and student engagement with departments and administrative staff.

✨ Key Features
 Personalized Dashboard: A smart summary view featuring today's classes, upcoming reminders, recent announcements, and internship updates.  
 Class Schedule Management: A clear weekly timetable view of courses, including times, locations, and instructors.  
 Reminders & Notifications: Custom alerts for exams, assignment deadlines, and registration milestones with timely notifications.  
 Internship Management: Browse, filter, and apply for cooperative training opportunities, while tracking application statuses and uploading required documents.  
 University Announcements: Broadcast and filter official announcements issued by colleges and academic departments.  
 In-app Messaging: Secure and structured communication between students and authorized academic staff or advisors.  
 Bilingual Localization: Full support for both English (LTR) and Arabic (RTL) user interfaces.  
 
🛠️ System Architecture & Tech Stack
 Architectural Approach: Built using a modular, layered architecture (Presentation, Business Logic, Data Access, and External Integration layers) and Service-Oriented Architecture (SOA) principles to ensure scalability and maintainability.  
 Database & Persistence: Relational database schema ensuring ACID compliance for users, schedules, reminders, internships, and messages.  
 External Integrations: Designed to support University SSO/Authentication services and cloud messaging APIs (such as Firebase Cloud Messaging) for real-time notifications.
